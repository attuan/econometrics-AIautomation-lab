## 1. 結論を先に

**条件つきで勧める。** 条件は「理論の新規性を売りにせず、実装と実データでの検証を売りにする」こと。

- **同じ問いに先に答えた研究がある。** Lee (2023) が、BLP 型の需要推定に弱識別に頑健な信頼集合を初めて当てた。「初めて」はもう取れない。
- **ただし穴は具体的に残っている。** Lee は丁度識別・均一分散・全パラメータ同時・合成データのみ。実データへの適用も公開コードも見つからなかった。
- **定番ライブラリは未対応である。** PyBLP 1.3.0 には、弱い操作変数の診断も頑健な信頼集合も無い（API の一覧と配布物の中身で確認）。

## 2. 問いと、なぜ今か

**問い**: ランダム係数ロジットの需要推定で、(a) 操作変数が弱いかをどう診断するか、(b) 弱いときにも被覆率が正しい信頼区間を、実用的な計算時間で出せるか。

**誰の判断が変わるか**

| 誰 | 何が変わるか |
|---|---|
| 需要推定を使う実証研究者 | 代替パターンを決めるパラメータ（ランダム係数の分散）の区間を、どちらの方法で報告するか |
| 合併審査などの実務家 | 弾力性・転換率の区間が狭すぎないか。Lee (2023) は仮想的独占者テストを例に挙げる |
| ライブラリの開発者 | 線形の操作変数法では標準の「第1段階の診断」に当たるものを、既定の出力に入れるか |

**なぜ今か**

- Berry・Haile のハンドブック章が、非線形モデルでの第1段階の診断について「明確な指針が常にあるわけではない」「さらなる進展が要るかもしれない」と書いている（[Berry & Haile (2021)](https://cowles.yale.edu/sites/default/files/2022-08/d2301_0.pdf)、4.2.6節を本文で確認）。
- Gandhi・Houde は、IIA 検定には「弱すぎる」の統計的な基準が付いていないと自ら書いている（[Gandhi & Houde (2019)](https://www.nber.org/papers/w26375)、改訂版の序論を本文で確認）。
- 道具の側は揃った。PyBLP が推定・最適操作変数・合成データ生成を担うので、頑健な推論だけを上に載せればよい（[PyBLP の API 一覧](https://pyblp.readthedocs.io/en/stable/api.html)）。

## 4. 未解決の問い

1. **実データで結論は変わるか。** 古典3データ（自動車2つ、シリアル）で、頑健な区間は通常の区間とどれだけ違うか。検索では、実データへの適用例は見つからなかった。
2. **診断は被覆率の歪みを予測するか。** IIA 検定・Cragg-Donald・条件つき F のどれが、通常の区間の過小被覆をいちばんよく当てるか。閾値は置けるか。
3. **過剰識別・不均一分散・クラスタの下で、計算は実用になるか。** Lee の次元削減は丁度識別と均一分散が前提である。非線形パラメータが2〜3個のとき、何時間かかるか。
4. **関心のある量の区間を出せるか。** 実務が欲しいのは、個々のパラメータ・弾力性・転換率の区間である。全パラメータの同時集合の射影は保守的になる。
5. **弱さと他の原因を切り分けられるか。** 境界（分散がゼロに近い）とシミュレーション誤差を制御した上で、操作変数の弱さだけの寄与を測れるか。

## 6. 外生変動の候補（識別の源と、シミュレーションの設計に読み替える）

### どの変動がどのパラメータを決めるか

| パラメータ | 決める変動 | 弱くなる場面 |
|---|---|---|
| 価格係数 | 費用の操作変数、他市場の価格、競合の特性（マークアップ経由） | 費用の操作変数が無い。製品数が多くマークアップが一定に近づく（Armstrong (2016)、要旨） |
| ランダム係数の分散（非線形パラメータ） | 市場間での選択肢集合の違い、製品の差別化の度合い | 特性の変動が市場内・市場間で乏しい。競合の特性の単純な和を使う（Gandhi・Houde） |
| 人口統計との交互作用 | 市場間の人口統計の違い、ミクロモーメント | 市場数が少ない |

Gandhi・Houde の整理では、非線形パラメータが弱識別であることは、データから IIA（ロジット）を棄却できないことと表裏である。

### 主張する性質

| 主張 | 確かめ方 |
|---|---|
| P1: 頑健な集合は、操作変数の強さによらず名目の被覆率を持つ | 合成データ。被覆率が名目から ±3 ポイント以内（1,000回なら標準誤差は約1ポイント） |
| P2: 通常の区間は、弱いとき過小被覆になる | 同じ設計で、通常の区間の被覆率を測る |
| P3: 診断の統計量は、P2 の過小被覆を予測する | 設計ごとの統計量の分布と被覆率の関係。閾値ごとの見逃しと誤警報 |
| P4: 強いとき、頑健な集合の長さは通常の区間に近い | 射影した区間の長さの比 |

### シミュレーションの設計（案。筆者の見解）

| 軸 | 水準 |
|---|---|
| 操作変数の強さ | 費用の操作変数と価格の相関を 0.05〜0.75（Lee と Conlon・Gortmaker の設計を踏襲） |
| 市場数・製品数 | 市場 13・20・94・200、製品 6・24・100（古典データの大きさに合わせる） |
| 非線形パラメータの数 | 1・2・3 |
| 操作変数の種類 | 競合の和、差別化（局所・二次）、最適操作変数の近似 |
| 識別の次数と誤差 | 丁度識別／過剰識別、均一分散／不均一分散／クラスタ |
| 供給側 | なし／あり |
| 交絡の制御 | 分散の真値をゼロから離す（境界）。積分は求積法で誤差を抑える（シミュレーション誤差） |

**識別の弱点**: 合成データの結論は生成過程に依存する。古典データに合わせて較正した設計で過小被覆が出なければ、「問題は小さい」が結論になる。

| Jin・Xie [arXiv 2609.15736](https://arxiv.org/abs/2609.15736)（2026年9月） | 条件つきモーメントでは識別されるのに、標準の GMM では最適操作変数でも識別されない反例。新しい2段階推定量 | 弱い操作変数の漸近論ではない。ただし「GMM の識別の失敗」を扱う最新の動きで、査読者は関連づけて読む | 要旨 |
| Ketz [JoE 2019](https://ideas.repec.org/a/eee/econom/v212y2019i2p413-432.html)、Brunner ほか [JoE 2025](https://ideas.repec.org/a/eee/econom/v247y2025ics0304407625000077.html) | 境界、シミュレーション誤差による歪みと不安定さ | 弱さ以外の原因。こちらは切り分けの対象として使う | 要旨 |

**検索で見つからなかったもの**

- 2025〜2026年の、BLP の弱識別に頑健な推論を主題とする新しい論文。arXiv の API で、要旨に次の語を含むものを新しい順に見た: 「weak identification + demand」（0件）、「weak instruments + demand」（2件、無関係）、「random coefficients logit」（7件）、「BLP」かつ econ.EM（14件）、「differentiated products + instruments」（5件）、「demand estimation + weak／identification-robust」（0件）。

**調べ切れていないもの**（検索の回数上限のため）: SSRN と NBER の個別検索、Gandhi・Houde の投稿状況、R（BLPestimatoR）・Stata・Julia の需要推定パッケージの機能、線形の弱操作変数ライブラリ（Stata の weakiv、Python の ivmodels）が非線形 GMM に使えるか。

## 8. AI が効く所・効かない所

| 工程 | 律速 | AI の効き |
|---|---|---|
| 文献の整理（弱識別の理論と IO の実務の橋渡し） | 情報処理 | 効く |
| 検定統計量の実装（S／AR 型、K、条件つき尤度比型、2段階） | コード量と検算 | 効く。Lee の表1の再現が検算になる |
| 大規模シミュレーション（設計の格子×1,000回） | 計算量 | 効く。並列で回せる |
| 古典データでの例示 | データは同梱 | 効く。許可は要らない |
| 部分ベクトル・弾力性の区間の理論（局外パラメータも弱いとき） | **理論の難しさ** | 効きにくい。既存の定理が当てはまる範囲を正しく見極めるのは人 |
| 「弱すぎる」の閾値を理論で正当化する | **理論の難しさ** | 効きにくい。シミュレーションでの経験則なら出せる |
| 計算を軽くする工夫（Lee の次元削減の一般化） | 理論と数値計算の半々 | 半々 |

律速は、データの許可ではない。**理論の保証をどこまで付けるか**である。経験的な検証と道具に絞れば、律速は AI の得意な側に寄る。

## 一次採点からの修正
