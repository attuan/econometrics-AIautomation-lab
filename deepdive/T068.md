## 2. 問いと、なぜ今か

**問い**: 観測されない異質性（有限混合のタイプ）をもつ動学的離散選択モデルを、実証でよくある大きさの標本で推定するとき、推定法の系統ごとに、偏り・信頼区間の被覆率・収束の失敗・反実仮想の誤差はどう違うか。

**なぜ今か**（事実と見解を分ける）。

## 6. 外生変動の候補

構造推定のテーマなので、「識別の源」と「シミュレーションの設計」に読み替える。

### 6.1 識別の源（どの変動がどのパラメータを決めるか）

| パラメータ | 決める変動 | 弱くなる条件 |
|---|---|---|
| タイプの割合とタイプ別の選択確率 | 同じ個体の選択の系列相関（パネルの期間） | 期間が短い。Kasahara・Shimotsu (2009) は識別に要る期間の条件を示す（検索結果の要約のみ。条件の数値はここに書かない） |
| 効用のパラメータ | 状態変数（走行距離など）に対する選択確率の傾き | 状態の変動が小さい。タイプと状態が強く相関する（動学的な選別） |
| 割引因子 | 効用に入らず遷移にだけ効く変数 | そうした変数が無いと識別されない。Arcidiacono・Miller の設計はこれを入れている |
| 初期条件 | 観測の開始時点の状態とタイプの相関 | 途中から観測する標本。Arcidiacono・Miller は初期のタイプ確率を状態の関数で推定する |

「小標本での性能」は、識別が弱くなる領域での挙動と重なる。偏りが推定法のせいか、識別の弱さのせいかを分ける設計が要る。

### 6.2 主張する性質と、確かめる設計（案。ロックで固定する対象）

| 軸 | 水準（案） |
|---|---|
| モデル | ①バスの交換（Arcidiacono・Miller の表1の設計を再現）、②参入・退出（Chen ほかの設計を縮小） |
| 個体数 N | 200、500、1000、5000 |
| 期間 T | 3、6、10、20 |
| 真のタイプ数 | 2、3 |
| 推定で仮定するタイプ数 | 1〜4（誤った指定を含む）と、BIC による選択 |
| タイプの分離 | 強い・弱い |
| 初期値 | 真値の近く、異質性なしの推定値、無作為。再出発の回数を振る |
| 推定法 | FIML（NFXP）、EM つき CCP、EM-NPL、MPEC。ベイズ法は余力があれば |
| 指標 | 偏り、RMSE、95%信頼区間の被覆率、収束の失敗率、局所解に落ちた割合、反実仮想の誤差、計算時間 |
| 反復 | 各セル500回以上（被覆率 95% の標準誤差が約1ポイントになる） |

- **主張する性質（仮説）**: (a) N が数百では、どの系統も被覆率が名目を下回る。(b) タイプ数の過少指定は、パラメータより反実仮想を大きく歪める。(c) 系統間の差より、初期化の差の方が大きい。
- どれも筆者の仮説である。(c) は Iskhakov ほかの教訓と Blevins・Kim の発見からの類推にすぎない。
- **弱点**: 実装の質が結果を決める。自分の実装が遅い・不安定なだけ、という批判を受ける。原著の表を再現してから比べる必要がある。

## 8. AI が効く所・効かない所

| 工程 | 律速は何か | AI の効き方 |
|---|---|---|
| 既存コード（Matlab・Gauss）を読み、Python に書き直す | 情報処理 | よく効く。再現ファイルの表と突き合わせて検証できる |
| 4系統の推定器の実装とテスト | 情報処理。ただし数値の安定性に勘所がある | 効く。Iskhakov ほかの例のように、内側の解法の選び方で結果が変わる。人が原著と照合する |
| 大量のシミュレーション | 計算の量 | よく効く。合成データなのでやり直しが速い |
| 文献の設定の表づくり | 情報処理 | よく効く。今回も本文から設定を抜けた |
| 「何を示せば論文になるか」の設計 | 着想と分野の相場観 | 効きにくい。査読者が何を新しいと見るかは、人の判断が要る |
| 理論（なぜ被覆率が崩れるか） | 理論の難しさ | 効きにくい。有限混合の漸近論は非標準である。説明なしの数表は弱い |
| データの許可 | 該当なし | 律速にならない。全部 T0 である |

律速は情報処理と計算である。データの許可は問題にならない。弱いのは「問いの価値」であり、AI では補えない。
