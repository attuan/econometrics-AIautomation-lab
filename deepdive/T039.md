## 1. 結論を先に

**着手を勧めない（元の構想のままでは）。**

- 元の問い「埋め込みを調整変数に入れた二重機械学習で、被覆率はどうなるか」には、既に答えた論文がある。[Shimizu (2026)](https://arxiv.org/abs/2607.17378) が理論・被覆率のシミュレーション・検定・実務指針を1本で出している。
- 平均処置効果については [Schulte ら (2025)](https://arxiv.org/abs/2506.14329) が ICML 2025 で条件を示した。需要推定は [Christensen と Compiani (2026)](https://arxiv.org/abs/2601.05374) が補正を出した。
- 残る隙間はあるが狭い。理論の新規性ではなく、実物の埋め込みを使った点検と道具の整備である。単独の論文としては弱い。

- **いちばんの勝ち筋**: 実物の埋め込み（BERT など）と実際の文章を使った半合成ベンチマークと、診断つきのライブラリ。T031 のライブラリの1機能として出す。
- **いちばんの懸念**: Shimizu (2026) は進行中の原稿で、著者が「シミュレーションを拡張中」と書いている。残る隙間を、著者自身が次の版で埋める可能性が高い。

## 2. 問いと、なぜ今か

- 実証研究で、文章や画像を事前学習モデルでベクトルにし、調整変数に入れる例が増えている。
- ベクトルは数百〜数千次元ある。標本が数千なら、次元と標本の大きさが近い。
- 問いは「そのとき処置効果の推定値と信頼区間は信用できるか。何を選べば安全か」である。
- 答えが出ると、文章を調整変数に使う実証研究者の手順が変わる。学習器の選び方と、報告すべき頑健性が決まる。
- 「なぜ今か」への答えは変わった。2025〜2026年に理論が一気に出た。今は「空白を埋める時期」ではなく「出た理論を使える形にする時期」である。

## 4. 未解決の問い

どれも筆者の見解である。「検索では見つからなかった」は、下の検索語で探した結果を指す。

1. **実物の埋め込みで、次元が標本に近いときの被覆率。** Shimizu の合成実験は200次元・n = 2,000 までで、埋め込みは小さな網で作った人工物である。実データの例は n が25万ある。経済学に多い「n が500〜5,000、埋め込みが768〜3,072次元」の点検は、検索では見つからなかった（検索語: semi-synthetic real text embeddings double machine learning coverage small sample）。
2. **主成分で次元を落とす実務。** 多くの実証研究は、埋め込みを主成分で数十次元に落としてから入れる。落とした成分に交絡が残るか、被覆率がどうなるかを扱う計量の論文は、検索では見つからなかった（検索語: PCA LLM text embeddings control variables regression inference）。Shimizu の本文に主成分の議論は無い。
3. **種を変えた埋め込みが手に入らないとき。** Shimizu の検定は、同じ課題で種だけ違う埋め込みを2本以上要る。商用 API の埋め込みは1本しか無い。代わりの診断（別モデル間の比較、次元の切り詰め）が同じ役を果たすかは、仮説の段階である。
4. **埋め込みそのものを「関心のある説明変数」にする場合。** 係数の解釈と推論は、調整変数の場合と違う問題になる。こちらは Battaglia ら (2024) の守備範囲に近く、T031 に属する。
5. **道具が無い。** `DoubleML` の文書の入口には、文章・画像の埋め込みの扱いは書かれていない（[DoubleML の文書](https://docs.doubleml.org/stable/index.html) で確認）。Shimizu の検定を実装した公開パッケージは、検索では見つからなかった。

## 6. 主張する性質と、それを確かめるシミュレーションの設計

手法のテーマなので、この章は読み替えて書く。絞り直した構想（半合成ベンチマーク）の設計である。予想はすべて仮定である。

| 主張（仮説） | 確かめ方 | 評価指標 | 弱点 |
|---|---|---|---|
| H-a: 実物の埋め込みでも、リッジは名目95%に近い被覆率を保つ。ラッソと木は保たない | 実際の文章を BERT で埋め込み、その線形・非線形の関数で処置と結果を人工的に作る。n を 500・1,000・2,000・5,000、次元を 384・768・1,024 で振る | 被覆率、偏り、区間の長さ。各セル 1,000 回以上 | 交絡を自分で作るので、現実の交絡の形を代表しない |
| H-b: 主成分で k 次元に落とすと、交絡が上位成分に無いときに被覆率が崩れる | 交絡を載せる成分の位置（上位・中位・下位）と k を振る | 被覆率と、k に対する偏りの曲線 | 「下位成分に交絡」が現実にどれだけあるかは別に示す必要がある |
| H-c: 種違いの埋め込みが無くても、別モデル間の推定値のばらつきが転移可能性の破れを検出する | 転移可能性を人工的に破った設計で、Shimizu の検定と代替の診断の棄却率を比べる | 大きさと検出力 | 別モデルは課題も違う。Shimizu の理論の外で、正当化が要る |

- どの仮説も、Shimizu の理論から予想がほぼ立つ。H-a が「理論どおり」なら、新しい知見は小さい。
- 論文になるのは、理論の予想が実物の埋め込みで外れた場合である。片側の結果に依存する。

## 8. AI が効く所・効かない所

| 工程 | AI が効くか | 理由 |
|---|---|---|
| 半合成データの生成、被覆率の大量計算 | 効く | 設計を振って回すだけ。計算量が律速 |
| 既存手法の実装と突き合わせ | 効く | Shimizu の検定は手順が本文に書いてある |
| ライブラリ・文書・テスト | 効く | 定型の作業 |
| 新しい理論（主成分の切り詰め、別モデル間の診断の正当化） | 効きにくい | 転移学習の理論と経験過程の議論が要る。ここが論文の価値を決める |
| 先行する著者より先に出すこと | 効かない | 相手は同じ問いを専業で進めている。速さで勝つ保証が無い |

- 律速は情報処理ではなく、**理論の新しさと競合の速さ**である。AI で回せる部分は、既に答えの見当が付いている部分である。

| 軸 | 現在 | 提案 | 理由 |
