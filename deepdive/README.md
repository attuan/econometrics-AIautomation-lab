# ディープダイブ（段階2）

上位10テーマを、1テーマ1文書（`<TID>.md`）で掘る。読んだ人が5分で「着手するか」を決められることが目標。
事実には出典を付ける。DOI は `tools/verify_dois.py` で照合する。
各文書には3〜4分の動画が付く（`video/videos/<TID>.js`。構成は `common/video/STYLE.md`「構成の型②」）。内容は文書にあるものだけで、判断は書かない。ポータルでは、各テーマのページの冒頭に埋め込まれる。

## 各文書の章立て（順番は固定）

1. **結論を先に**: 着手を勧めるか。理由を3行で。
2. **問いと、なぜ今か**: 答えが出ると誰の判断が変わるか。
3. **文献の地図**: 転換点の論文、推定値の範囲、割れている点。
4. **未解決の問い**: 3〜5個。
5. **使えるデータ**: 名前、観測単位・期間・n、入手手順、所要期間、費用、秘匿区分（T0/T1/T2）、公開できるか。
6. **外生変動の候補**: 制度変更・閾値・割当のルール。それぞれの識別の弱点。
7. **競合**: 近い問いを追うチームと、出ているワーキングペーパー。
8. **AI が効く所・効かない所**: ボトルネックは情報処理か、データの利用許可か。
9. **6か月計画**: 月ごとの成果物と、撤退条件。
10. **判断（人が書く）**: Go／No-Go、理由、次の一手。

### この一覧を読むときの注意

- 論文の多くは、全文を通読できていない。各文書の「文献の地図」に、読んだ深さ（本文／要旨／検索結果の要約のみ）を書いてある。
- 10本のうち7本で、ウェブ検索が回数の上限に達した。2025〜2026年の SSRN・NBER の調べは不十分である。「検索では見つからなかった」は、無いことの証明ではない。
- T036 と T099 の「勧めない」は、本文を読めていない先行論文（Chen・Kimura・Inoue、Amada）に依っている。人が本文を読めば、結論が変わりうる。
- T076 の入札調書には、個人事業主の氏名が含まれうる。`ETHICS.md` 第4条との関係を、人が決める必要がある。
- 重なりがある。T039 は T031 に、T068 は T067 に統合する案が出ている。T068 と T069 は、動学モデルの基準実装を共有できる。
