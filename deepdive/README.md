# ディープダイブ（段階2）

上位10テーマを、1テーマ1文書（`<TID>.md`）で掘る。読んだ人が5分で「着手するか」を決められることが目標。
事実には出典を付ける。DOI は `tools/verify_dois.py` で照合する。

## 各文書の章立て（順番は固定）

1. **結論を先に**: 着手を勧めるか。理由を3行で。
2. **問いと、なぜ今か**: 答えが出ると誰の判断が変わるか。
3. **文献の地図**: 転換点の論文、推定値の範囲、割れている点。
4. **未解決の問い**: 3〜5個。
5. **使えるデータ**: 名前、観測単位・期間・n、入手手順、所要期間、費用、秘匿区分（T0/T1/T2）、公開できるか。
6. **外生変動の候補**: 制度変更・閾値・割当のルール。それぞれの識別の弱点。
7. **競合**: 近い問いを追うチームと、出ているワーキングペーパー。
8. **AI が効く所・効かない所**: ボトルネックは情報処理か、データの利用許可か。
9. **6か月計画**: 月ごとの成果物と、撤退条件。
10. **判断（人が書く）**: Go／No-Go、理由、次の一手。
