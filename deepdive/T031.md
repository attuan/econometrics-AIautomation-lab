## 1. 結論を先に

**条件つきで勧める。元の構想（偏りの大きさを示し、補正を実装する）のままなら勧めない。**

- 元の構想は、既に済んでいる。補正の理論・公開パッケージ・実務指針・経済学での適用例が、2025〜2026年に出そろった。
- 一次採点の「公開パッケージは確認できなかった」は誤りだった。R と Python に少なくとも7つある（7章）。
- 残る隙間は「手法どうしの横並びの比較」と「どれを使うかの判断手順」である。新しい推定量ではなく、ベンチマーク論文と統一ライブラリなら勝ち目がある（筆者の見解）。

**いちばんの勝ち筋**: 5系統の補正を、経済学で典型的な設定（説明変数側の誤り、固定効果、クラスタ、検証標本の有無）で同じ土俵に載せ、どの条件でどれが壊れるかを示す比較と、それを1つの入口で呼べるライブラリ。

**いちばんの懸念**: 有力な著者のチームが、少なくとも10組、同じ場所に密集している（7章）。比較論文も、彼らの次の1本で埋まるおそれがある。

## 2. 問いと、なぜ今か

### 問い

LLM や機械学習が付けたラベル・点数を回帰に入れると、推定値はどれだけ偏るか。どの補正を、どの条件で使えばよいか。

### 答えが出ると誰の判断が変わるか

| 誰 | 変わる判断 |
|---|---|
| テキスト・画像から変数を作る実証研究者 | 人手ラベルを何件取るか。どの補正を使うか。補正なしで報告してよいか |
| 査読者・編集者 | LLM 変数を使う論文に、何の点検を求めるか |
| このラボ自身 | 段階5（文献をデータにする）で AI が抽出した値を、どう補正して使うか |

### なぜ今か

- 既存研究の再現で、LLM のラベルを使うと誤った結論が頻発すると報告された。37課題・21研究の再現である（[Baumann ほか (2025)](https://arxiv.org/abs/2509.08825)。要約のみ確認。割合の数値は本文未確認のため書かない）。
- モデルやプロンプトを変えると、係数の符号・大きさ・有意性が変わると報告された（[Ludwig・Mullainathan・Rambachan (2025)](https://arxiv.org/abs/2412.07031)）。
- 補正手法は2023年以降に急増した。系統が5つに分かれ、利用者から見て選べない状態にある（筆者の見解。3章の表が根拠）。

### 関連テーマとの切り分け

| テーマ | 扱うもの | T031 との境界 |

| T033 | LLM を使ってよい条件の検査（学習データの漏れ、プロンプトへの感度、検証標本の要否） | 補正の**前**の関門。漏れの検査は T033 に置く。T031 は「検証標本がある／無いときに、どう補正するか」だけを扱う |

- Battaglia らの論文は、トピックの割合のような「真の値が定義しにくい」変数も扱う。この部分は T039 に近い。

## 3. 文献の地図

### 補正の5系統

| 系統 | 考え方 | 人手ラベル（検証標本） | 代表 |
|---|---|---|---|
| A. 明示的な偏り補正・同時推定 | 誤分類率から偏りの式を出して引く。または回帰と測定モデルを同時に最尤推定する | 少数、または不要（同時推定） | Battaglia ほか |
| B. 設計にもとづく補正 | 人手ラベルを取る確率を研究者が決め、二重に頑健な擬似結果変数を作る | 必要（抽出確率が既知） | Egami ほか、Carlson・Dell |
| C. 予測を使った推論 | 予測だけの推定値に、ラベルつき標本で測った補正項を足す | 必要 | Angelopoulos ほか、Kluger ほか |
| D. 検証標本での回帰補正 | 測定誤差を説明変数に回帰し、係数から引く。モーメントごとに補正する | 必要 | Ludwig ほか、Duan・Pelger |
| E. 操作変数 | 別の予測（別のモデル、別の分割、アンサンブルの個々の学習器）を操作変数にする | 不要 | Burtch ほか、Canen・Enamorado |

### 割れている点

- **検証標本は必須か。** Ludwig らは必須と言う。Christensen・Hansen は、経済学では検証データが無いことが多いとして、不要な補正を勧める。操作変数の系統も不要とする。
- **操作変数型は妥当か。** Battaglia らは、操作変数型の補正は検証標本と本標本が同程度の大きさのときだけ妥当で、信頼区間の被覆が不足すると書いている（v4 本文）。Burtch らと Canen・Enamorado は妥当と主張する。同じ設定での直接の比較は、検索では見つからなかった。
- **DSL と PPI のどちらが良いか。** EMNLP の比較では、データによって逆転する。

### 推定値の範囲

横並びで引ける数値は少ない。書けるのは次だけである。

- Battaglia らのシミュレーションの設定: 本標本 25,000、検証標本 1,000、誤分類の確率 0.012（v4 本文）。この小さな誤分類でも被覆が歪む、と本文は述べる。被覆率の数値は図にあり、読めていない。
- Duan・Pelger の適用例: 人手ラベルだけの信頼区間に比べ、幅がおよそ半分（NBER の要旨）。標本の大きさは未確認。
- それ以外の偏りの大きさ・被覆率は、本文を読めていないので書かない。

## 4. 未解決の問い

検索の範囲で、答えが見つからなかった問いである。「空いている」と断定はできない。

1. **5系統を同じ設定で比べると、どれがどこで壊れるか。** 既存の比較は系統 B と C だけ、結果変数だけ、2値ロジットだけである（EMNLP 2025）。説明変数側・系統 A と D と E を含む比較は、検索では見つからなかった。
2. **検証標本が無い補正（同時推定・操作変数）は、検証標本がある補正と同じ答えを出すか。** 人手ラベルがある公開データなら、直接確かめられる。
3. **誤分類が、他の説明変数や結果変数と相関するとき、各手法はどうなるか。** Ludwig らは誤差が非古典的になりうると指摘する。Battaglia らは直交の仮定を緩めると式が複雑になると書く。
4. **固定効果・クラスタ・パネルで何が起きるか。** DSL は固定効果つきの線形回帰を実装済み。MAR-S は差の差を扱う。しかし、誤分類が単位内で相関する場合の性質を調べた研究は、検索では見つからなかった。
5. **人手ラベルを何件取ればよいか。** PPI については検出力の式と R パッケージが2026年3月に出た（[arXiv 2603.16041](https://arxiv.org/abs/2603.16041)。検索結果の要約のみ。著者名は未確認。2標本比較と 2×2 表が対象）。回帰係数・説明変数側の設計は、Duan・Pelger が最適設計を出している。手法をまたぐ実用的な目安は、検索では見つからなかった。

### 主張する性質（仮説。まだ何も確かめていない）

| 番号 | 主張 | 棄却される条件の案 |
|---|---|---|
| P1 | 補正なしの推定は、誤分類率が数%でも名目95%の被覆を保てない | 誤分類率5%以下の全設定で、被覆率が93%以上 |

### シミュレーションの設計

| 軸 | 水準 |
|---|---|
| 生成変数の位置 | 説明変数（関心のある変数）／調整変数／結果変数 |
| 変数の型 | 2値／多値／連続の点数 |
| 誤りの大きさ | 誤分類率 1・5・10・20% |
| 誤りの構造 | 無作為／他の説明変数と相関／結果の誤差項と相関／偽陽性と偽陰性が非対称 |
| 標本 | 本標本 1千・1万・10万、検証標本 0・100・500・2,000 |
| 検証標本の取り方 | 単純無作為／層別／不確かな所に集中 |
| 回帰の形 | 最小二乗法／ロジット／固定効果／クラスタ内で誤りが相関 |
| 比べる手法 | 補正なし、検証標本だけ、系統 A（`MLBC`）、B（`dsl`、`mar-s`）、C（`ppi_py`、`ipd`、`PTDBoot`）、D（Ludwig らの2本の回帰を自作）、E（分割標本・複数 LLM の操作変数） |
| 評価指標 | 偏り、平均二乗誤差の平方根、95%区間の被覆率、区間の幅、計算時間、失敗率 |

- 全部の組合せは多すぎる。中心の設定を1つ決め、軸を1つずつ動かす。
- 半合成の実験も入れる。人手ラベルのある公開データで、実際の LLM の誤りをそのまま使う。真の係数は、全件の人手ラベルで推定した値とする（EMNLP の比較と同じやり方）。
- 1周は数分〜数時間で回ると見込む（筆者の見解）。同時推定（系統 A の `one_step`）だけは重い。

### この設計の弱点

- 既存パッケージは、対応する設定が違う。「比べられない組合せ」が多く出る。それ自体を表にして示す。
- 他人の手法を自分で実装すると、実装の誤りで不当に悪く見せるおそれがある。著者の公開コードを使い、論文の数値を再現してから比べる。
- 設定を選ぶ自由度が大きい。設定と評価指標をロックで固定する（手法トラックの決まり）。

## 8. AI が効く所・効かない所

| 工程 | 律速 | AI の効き方 |
|---|---|---|
| 文献の整理（5系統、数十本） | 情報処理 | よく効く。ただし月に数本のペースで新しい論文が出る。追い続ける必要がある |
| 既存パッケージの呼び出しと、共通の入口の実装 | 情報処理 | よく効く |
| 各論文の数値の再現 | 情報処理 | 効く。再現できない場合の原因究明は人の判断が要る |
| シミュレーションの大量実行 | 計算 | よく効く。合成データなので制約が無い |
| 公開データへの LLM ラベルの付け直し | 計算・費用 | 効く |
| 「どの設定が経済学で典型的か」を決める | 分野の知識 | 効きにくい。ここで論文の価値が決まる |
| 固定効果・相関する誤りの理論 | 理論の難しさ | 効きにくい。新しい漸近論が要るなら、人が主導する |
| 有力チームに対する位置づけ | 判断 | 効かない。人が決める |

- データの許可は律速にならない。
- 律速は「何を主張すれば新しいか」である。一次採点の F（AI 増幅度）5点は、工程としては正しい。しかし、速く回せても、主張が既出なら意味が無い。
