T109　人の被験者と LLM エージェントを混ぜた実験の推定量と最適配分

トラック: 推定量・計量手法（method）
調べた日: 2026-11-21
段階: 段階2（ディープダイブ）
一次採点: 合計 76.2 点、110件中2位（theme/research/scored.csv）
読み方の注意: 論文とページは、取得ツール（ページを要約して返す道具）を通して読んだ。例外は van Loon・Kanopka (2026) の1本だけで、公開 PDF から抜き出した本文を直接読んだ（補足資料は見出しと末尾だけ）。「読んだ深さ」の列はこの前提で書いた。
著者の所属は確かめていないので書いていない。「検索結果の要約のみ」と書いた文献の URL は、検索結果に出たもので、ページは開いていない。その文献の数値は写していない。
ウェブ検索は約27回行った。回数の上限には達していない。それでも SSRN・NBER の本文は読めていない。「検索では見つからなかった」は、無いことの証明ではない。

1. 結論を先に

勧めない。残すなら、T031 に統合して「経済実験で利得がどれだけ出るかの実測」に絞る（条件つき）。

  • 一次採点が「残る穴」とした実装と最適配分は、既に埋まっている。R パッケージ mixedsubjects（CRAN、2026年7月）が、7つの推定量と、予算のもとでの配分の関数を持つ（7章）。
  • 利得は小さいと報告されている。既存の実証では、有効標本サイズの増加は13〜14%が上限である。LLM の予測を回帰の調整変数に入れる方が安全だ、という論文も出た（3章）。
  • 残る穴は「誘因つきの経済実験（ゲーム・選好の測定）での実証」だけである。検索では見つからなかった。ただし、予想される答えは「利得は小さい」であり、単独の論文としては弱い（筆者の見解）。

いちばんの勝ち筋: 公開個票のある経済実験を10本以上集め、腕（処置群・対照群）の中での人と LLM 予測の相関を実験の型ごとに測る。そこから「混ぜる価値がある実験の型」と「無い型」の地図を作る。T031 のベンチマークの1章にする。

いちばんの懸念: 提案者本人（van Loon・Kanopka）が、次の版で実データの適用例を足すとみられる。経済学側でも、有力な著者のチームが隣の問いを埋めている（7章）。

2. 問いと、なぜ今か

問い

人の被験者の一部を LLM の予測で補うと、処置効果の推定はどれだけ精密になるか。人と予測に、予算をどう配ればよいか。経済実験でも成り立つか。

答えが出ると誰の判断が変わるか

誰変わる判断
実験を設計する研究者人の被験者を何人集めるか。LLM の予測を買うか。どの推定量で分析するか
研究費の審査者・事前登録の査読者「LLM で標本を補う」設計を認めるか。何の点検を求めるか
このラボ自身段階6（シミュレーター）で、LLM エージェントの出力を人のデータの補助に使ってよいか

なぜ今か

  • 設計の提案が2025年に公刊された（Broska・Howes・van Loon (2025)）。2026年には、推定量の族とパッケージ（van Loon・Kanopka (2026)）、整理と批判（Hullman ほか (2026)）、回帰調整による対案（Arbour ほか (2026)）が続いた。
  • LLM が実験の処置効果を高い相関で当てる、という結果が Nature に載った（Ashokkumar ほか (2026)）。「それなら被験者を減らせる」という期待が広がっている（筆者の見解）。
  • ただし、効果の当たり方と、個人の回答の当たり方は別である。混ぜる設計の利得を決めるのは後者である（3章）。この区別が、今いちばん誤解されやすい（筆者の見解）。

関連テーマとの切り分け

テーマ扱うものT109 との境界
T109（本書）無作為化実験で、結果変数の一部を LLM の予測で補う。推定対象は人の平均処置効果。設計の段階で、人と予測の数を決める処置は無作為。予測は処置の前の情報だけで作る
T031観察データの回帰に、LLM が付けたラベル・点数を変数として入れるときの偏りの補正「真の値」は人手のラベル。説明変数側の誤りが主題。設計より、事後の補正を扱う
T033LLM を使ってよい条件の検査（学習データの漏れなど）補正の前の関門。T109 でも漏れは利得を過大に見せる（6章）
  • 道具は重なる。T109 の推定量の基礎は、T031 の系統 B（設計にもとづく補正）と系統 C（予測を使った推論）である。van Loon・Kanopka 自身が、基本の推定量は PPI・DSL と「機能的に同じ」と書いている（本文）。
  • T031 のシミュレーションの設計には、「生成変数の位置＝結果変数」の水準が既にある（deepdive/T031.md 6章）。T109 は、そこに「処置が無作為」「人と予測の配分」を足したものと読める。
  • 統合を勧める（筆者の見解）。 T109 を独立のプロジェクトにすると、T031 と同じパッケージ群を2度包むことになる。T031 のベンチマークに「実験の結果変数」の章として入れる方が、重複が無い。
  • 統合しない理由があるとすれば、利用者が違うことである。T031 は観察データの実証家、T109 は実験の設計者に向く。

3. 文献の地図

4つの立場

立場考え方人の標本代表
A. 置き換えLLM の回答を、人の回答の代わりに使う不要「silicon sampling」と呼ばれる。妥当性の保証は無い
B. 予測を使った推論（混合被験者）人だけの推定値に、予測で作った補正項を足す。人の標本で予測の偏りを測る必要（無作為に選ぶ）Broska ほか、van Loon・Kanopka
C. 回帰調整予測を、事前の共変量として回帰に入れる。新しい推定量は使わない全員が人Arbour ほか
D. 偏りの関数を学ぶ少数の人のデータで「LLM の回答→人の回答」の写像を学び、補正した回答で推定する必要（学習用）Wang ほか、Zhang ほか
  • B と C は近い。調整の強さを最適に選ぶ PPI++ は、予測を線形に較正した PPI と漸近的に同じだ、とされる（van der Laan・van der Laan (2026)。検索結果の要約のみ）。
  • 違いは、予測だけを持つ単位（人の結果が無い単位）を使うかどうかである。B は使う。C は使わない。

転換点の論文

論文何を示したか何が残ったか読んだ深さ
Broska・Howes・van Loon (2025)。Sociological Methods & Research 54巻3号LLM の予測を「情報があるかもしれない観測」として扱う設計。PPI を実演し、拡張した。PPI 相関（人と予測の入れ替えやすさの指標）、PPI の有効標本サイズ、人と予測の配分を決める検出力分析を出した要旨には数値が無い。適用例の中身は、他の論文の記述でしか確かめていない（下の「推定値の範囲」）要旨（RePEc の書誌ページ）
van Loon・Kanopka (2026)。SocArXiv、2026年4月（v1）混合被験者の無作為化実験を定式化。3つの設計条件（無作為割当・無作為抽出・無作為なラベルづけ）のもとで、有限標本で不偏な7つの推定量。腕ごとに調整の強さを変える推定量と、同じ単位の両腕の予測の差を使う推定量（DiP）が新しい。パッケージ mixedsubjects は、試行調査・単価・予算から、推定量と配分を勧めるv1 の本文と、補足資料の見出しには、実データの適用例が見当たらない。 結論には「実証的に価値を示した」とあるが、対応する節を見つけられなかった。共変量・クラスタ・複数の予測は扱っていない（パッケージの文書）本文（公開 PDF の本文を通読。補足資料は見出しと末尾の節だけ）
Hullman・Broska・Sun・Shaw (2026)。2026年2月「発見的な検証」（人と似ていることを示す）と「統計的な較正」（人の標本で補正する）を対比。確証的な研究には後者が要る、と主張。較正の利得は、LLM の精度と、人の回答の予測しやすさで頭打ちになるより効率のよい較正、人の回答の「予測できる上限」の測定を今後の課題に挙げる本文（v1 の HTML の前半約55%。取得ツールの要約）
Arbour・Ben-Michael・Feller・Lal・Yuan (2026)。KDD 2026、2026年6月新しい推定量は要らない、と主張。予測を共変量として回帰調整に入れれば、分散は 1−ρ² 倍になる（ρ は腕の中での結果と予測の相関）。予測が役に立たないときは、ただの平均の差に戻る。調整の強さを決めない PPI 型の推定量は、ρ が0.5を下回ると分散を増やす。Broska らの設計は推定対象を「人と合成の混合母集団」に変える、とも指摘人の結果が無い単位を足す場合は、本文で確かめられなかった。混合設計への拡張を今後の課題に挙げる本文（v1 の HTML の約9割。取得ツールの要約）
Mani・Xu・Lipton・Oberst (2025)。v2 は2026年6月PPI++ の「ただで得をする」性質は漸近だけ。有限標本では、人だけの推定より誤差が大きくなる場合がある。正規分布なら、相関が 1/√(n−2) 以上でないと改善しない平均の推定が対象。処置効果・小さな実験室実験での大きさは未確認要旨
Krsteski ほか (2025)。書誌の照合では ACL 2026調査の合成回答。合成だけなら偏りは24〜86%。補正を組み合わせると5%未満になり、有効標本サイズは最大14%増える。人の回答は、微調整より補正に回す方がよい調査の母集団の割合が対象。実験の処置効果ではない要旨
Wang・Zhang・Zhang ほか (2024)。書誌の照合では Marketing Scienceコンジョイント分析で、LLM の回答と人の回答を統計的に組み合わせる。COVID-19 ワクチンの選好で、データと費用を24.9〜79.8%節約。単純な置き換えでは節約できないコンジョイント（選択の繰り返し）が対象。利得が大きい理由は本文未確認要旨（v3）
Ye・Yoganarasimhan (2026)。v2 は2026年7月複数の設問に人の回答をどう配るか。LLM が当てにくい設問に多く配る閉じた式。試行調査なしで配分を決めるメタ学習。平均二乗誤差を11.4%・10.5%下げる調査が対象。実験の腕の間の配分ではない要旨
Zhang・Li・Hortaçsu・Ye・Chernozhukov・Ni・Huang (2025)。v4 は2026年7月。書誌の照合では ACL 2026 Industry少数の人のデータで LLM の選択を補正し、通常の計量手法で需要の弾力性と処置効果を推定する。地域の実地実験で、10%の地域で較正した推定が、全体の実験の推定に近い立場 D。不偏性の保証の範囲は未確認要旨
Ashokkumar・Hewitt・Ghezae・Willer (2026)。Nature 656巻70本の調査実験（469の効果、119,330人）で、GPT-4 の予測した処置効果が実測と強く相関。ただし効果の大きさを過大に見積もる。15本のメガスタディ（606の効果）では相関が弱い効果どうしの相関であって、個人の回答の相関ではない。混ぜる設計の利得は、ここからは分からない要旨（著者の所属機関の紹介ページ。相関の数値は載っていない）
Peng ほか (2025)。v5 は2026年4月2,000人超の「デジタルツイン」（本人の500問超の回答から作った LLM）を、19本の事前登録研究・164の結果変数で検証。人の回答との相関は平均 r = 0.20。素の LLM より少し良いだけ相関の定義（腕の中か、全体か）は要旨からは分からない要旨

割れている点

  • 予測だけの単位を足すべきか、共変量に入れるだけでよいか。 van Loon・Kanopka は足す（立場 B）。Arbour らは入れるだけでよいと言う（立場 C）。同じデータでの直接の比較は、検索では見つからなかった。
  • 推定対象は変わるか。 Arbour らは、Broska らの設計は推定対象を混合母集団に変えると書く。van Loon・Kanopka は、3つの設計条件のもとで人の平均処置効果を不偏に推定すると書く。後者は予測を無作為抽出した同じ母集団の単位に付けるので、筆者の見解では両立する。ただし、原文での確認が要る。
  • 利得は大きいか。 社会学・統計の側は13〜14%と報告する。マーケティングの側（Wang ほか）は25〜80%の節約と報告する。対象（処置効果か、選択モデルの係数か）と方法（立場 B か D か）が違う。

  • 相関から利得の上限を見積もれる。予測を無限に足せても、分散は 1−ρ² 倍までしか減らない（Arbour らの式）。有効標本サイズの倍率は 1/(1−ρ²) である。
  • 筆者の計算: ρ = 0.2 なら1.04倍、0.37なら1.16倍、0.5なら1.33倍、0.7なら1.96倍。
  • 上の実測（ρ は0.1〜0.4）からは、利得は数%〜16%である。被験者を半分にできるのは、ρ が0.7を超えるときだけである。
  • 誘因つきの経済実験での ρ は、どの文献にも見つからなかった。

4. 未解決の問い

検索の範囲で、答えが見つからなかった問いである。「空いている」と断定はできない。

  1. 誘因つきの経済実験で、腕の中の相関 ρ はいくつか。 独裁者ゲーム・公共財・リスクや時間の選好の測定などである。既存の実測は、調査実験・道徳判断・広告に限られる。LLM は人より合理的に答えやすい（Peng らの「過度の合理性」）。筆者の仮説では、ρ は調査実験より低い。
  2. 混合設計（立場 B）と回帰調整（立場 C）を同じ実験で比べると、どちらが良いか。 予測だけの単位を足す価値があるかどうかの問いである。Arbour らは今後の課題としている。
  3. 試行調査で決めた配分は、本番で当たるか。 mixedsubjects の optimal_design() は、小さな試行調査から腕ごとのモーメントを推定する。別の設定（デジタルツインと A/B テスト）では、配分の自由度を増やしても本番の誤差は下がらず、不確かさに罰を付けた配分の方が良かった（Ye・Deng・Candogan (2026)。NeurIPS 2026 のワークショップ。要旨のみ）。処置効果の推定量7つについての検証は、検索では見つからなかった。
  4. 実験室の小さな標本（腕あたり50〜200人）で、不偏性と被覆率は保たれるか。 Mani らは、PPI++ が有限標本で損をする条件を示した。交差適合つきの7推定量の被覆率を、実験室の規模で測った研究は、検索では見つからなかった。
  5. 被験者どうしが影響しあう実験（ゲーム、市場）で、設計条件は成り立つか。 van Loon・Kanopka は干渉が無いことを仮定する。経済実験の多くは、セッション内で被験者が相互作用する。
  6. 処置前の共変量を入れた後に、LLM の予測はどれだけ足しになるか。 Arbour らの検索実験では、処置前の結果変数が15.5%、予測の追加は約1ポイントだった。経済実験では、処置前の結果変数が無いことが多い。

半合成実験の設計

人の個票がある実験を使う。全員の人の結果から計算した処置効果を「真の値」とする。人の標本を間引き、間引いた単位には LLM の予測だけを残す。

  • 純粋な合成データの実験も置く。ρ・腕ごとの相関の差・予測の非線形な誤りを自由に動かし、P2 と P5 の境界を調べる。
  • 1周は、LLM の予測を一度作って保存すれば、数分〜数時間で回ると見込む（筆者の見解）。予測の生成は、モデルと実験の数に比例して時間と費用がかかる。

この設計の弱点

  • 学習データの漏れ。 公刊済みの実験は、LLM の学習データに入っているおそれがある。その場合、ρ は過大に出る。モデルの知識の締切日より後に公開されたデータ（Twin-2K-500 の追加調査など）と分けて報告する。完全には除けない。
  • プロンプトの自由度。 予測の作り方を変えると、ρ は動く。Arbour らは、試行調査での調整が p ハッキングになると警告している。予測の手順をロックで固定する。
  • 実験の選び方。 個票が公開されている実験は、偏った標本である。「経済実験一般」への一般化はできない。型ごとの結果として報告する。
  • 相互作用とクラスタ。 ゲームではセッション内で結果が相関する。単位を間引くと、相手のいない単位ができる。1回きり・戦略法（相手の選択ごとに決める方式）の実験に限るか、セッション単位で間引く。
  • モデルの版。 商用の LLM は版が変わり、同じ予測を再現できない。予測そのものを保存して公開する。公開の重みのモデルを1つは入れる。
  • 半合成の限界。 人の標本を間引くのは事後の操作である。事前に予測を作り、事前登録して人を集める本物の混合実験とは違う。本物の実験は、この計画に入れていない。
