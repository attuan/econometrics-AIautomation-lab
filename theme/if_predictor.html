数値はレポートからの転記で、このラボでは再計算していない。
このメモは段階1（テーマの採点軸）の見直しの材料である。軸を変えるかどうかは人が決める（◆、DECISIONS.md D3・D3b）。

結論を先に

  1. 題目と要旨だけで、掲載誌の格はかなり当たる。 既知の雑誌なら、雑誌平均の順位相関は ρ=0.91。論文単位では ρ=0.57、R²=0.39。
  2. しかし未知の雑誌に移すと弱くなる。 雑誌単位で ρ=0.41〜0.46、論文単位の R² はほぼ0。学んだものの多くは「どの雑誌らしいか」である。
  3. 効いたのは内容よりも書き方だった。 最も重要な群は「文体・構成」。上位誌らしい書き方（+）、小幅な拡張に見える書き方（−）、文法の誤り（−）が上位に来る。
  4. 目的変数の IF には癖がある。 被引用の多い分野・サーベイ・MDPI 系が高く、理論の雑誌が低く出る。モデルは「漸近理論や技術的な言葉は IF を下げる」と学んでいる。これは質の差ではない。
  5. ラボへの示唆（筆者の見解）: いまの15軸には、書き方・打ち出し方（一般の関心に届くか、小幅な拡張に見えないか）を見る軸がない。一方で IF をそのまま目標にすると分野の被引用慣行を拾うので、「上位誌らしさ」は別の目標で測り直す必要がある。

  • だから「漸近理論・技術的な言葉は −」は、理論の雑誌の IF が低いことを学んだ結果である。理論の論文が悪いという意味ではない。

5. 注意点

  • IF は雑誌単位の値である。 同じ雑誌の論文は同じ目的変数を持つので、論文単位の R² には上限がある。
  • 要旨の出所で標本が偏るおそれ。 Crossref に要旨がある雑誌とない雑誌で、出版社が偏る。
  • OpenAlex の値は JCR の IF と水準が違う。 順位は近いが、数値をそのまま比べない。
  • LLM の事前知識が混ざる。 「上位誌らしい書き方」「決まり文句」の判定には、LLM が持つ雑誌の格のイメージが入る。書き方そのものの効果と、雑誌を言い当てていることを分けられていない。
  • 因果ではない。書き方を直せば上位誌に載る、とは言えない。

  • 140問の判定は「要旨を読めば答えが書いてある」型の問いが多く、決定モデルが得意な部類である。
