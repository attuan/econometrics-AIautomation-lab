# 経済学で高く評価される貢献とは何か：「渋い問い」のメタ研究の構想（2026-11-24）

> 状態: **構想メモ（未着手）**。雑談で出た「経済学は渋い問いが多い」という話と、題目と要旨から掲載誌の格を当てる予備的な分析（非公開）から出た着想。

> 下の「貢献の型」は筆者（AI）の仮説で、まだデータで確かめていない。例に挙げた論文は書誌だけを照合した（本文は未確認。文献マスター表の `read_depth = biblio`）。

## 3行で言うと

1. **問い**: 計量経済学の一流誌に載る論文は、二流・三流誌の論文と、どの「貢献の型」で違うのか。
2. **仮説**: 一流誌を分けるのは題材の派手さではない。「多くの研究者のやり方や信念を変えるか」である。だから見た目の渋い問いが一流誌に多い。
3. **方法**: 題目と要旨に、はい／いいえの質問を決定モデルで当てて特徴量にする。目的変数は雑誌の格（一流／二流／三流）とする。IF は分野の被引用慣行を拾うので使わない。

## 1. 着想：「渋い」の正体

渋いのに一流誌に載り、広く引かれた論文の例。

| 問い（見た目は地味） | 論文 | なぜ評価されたか（筆者の見解） |
|---|---|---|
| DiD の標準誤差は信用できるか | Bertrand, Duflo & Mullainathan (2004, QJE) `bertrand2004` | 多くの実証論文が有意を過大に報告していたことを示し、標準誤差の付け方を変えた |
| 処置の時期がずれる DiD で、二方向固定効果は何を推定しているか | Goodman-Bacon (2021) `goodmanbacon2021`、Callaway & Sant'Anna (2021) `callaway2021`、de Chaisemartin & D'Haultfœuille (2020) `dechaisemartin2020` | 既存の多くの推定値の解釈を変え、代わりの推定量を標準にした |
| 操作変数が弱いと何が起きるか | Staiger & Stock (1997, Econometrica) `staiger1997` | 弱い操作変数を見分ける実務の目安が広まるきっかけになった |
| 最低賃金を上げると雇用は減るか | Card & Krueger（1993 NBER WP。1994 AER 版は書誌未照合）`card1993` | 古い問いに、自然実験の識別で通説と違う答えを出した |
| 効果がばらつくとき、IV は何を推定しているか | Imbens & Angrist (1994, Econometrica) `imbens1994` | ばらばらだった IV 推定値の解釈を、一つの枠組み（LATE）にまとめた |

共通点は、**表面は小さくても、読んだ後にやり方や信念を変える人が多い**ことである（筆者の見解）。

## 2. 仮説：評価される貢献の型

| 型 | 中身 | 例 |
|---|---|---|
| C1 誤りを正す | 広く使われている手続きの欠陥を示し、直し方も出す | DiD の標準誤差、二方向固定効果 |
| C2 道具を作る | 多くの人が使う推定量・検定・ソフトウェア | 合成コントロール法 `abadie2010`、DML `chernozhukov2018a` |
| C3 大きな問いに信頼できる答え | 古い重要な問いに、きれいな識別で答える。通説と違えばなお強い | 最低賃金 |
| C4 新しいデータで見せる | 行政記録の接続などで、見えなかったものを見せる | |
| C5 まとめる枠組み | ばらばらの結果や推定値を一つの考え方で解釈できるようにする | LATE |
| C6 言い切れる帰無 | 狭い信頼区間で、大きな効果を排除する | |
| X 小幅な拡張（負） | 既知の手法を新しい国・データに当てる。仮定を少し緩める | 予備的な分析で、格を下げる方向に強く効いた |

一つの物差しにまとめると、次のとおり（仮説）。

> **貢献の大きさ ≈ 読んだ後にやり方や信念を変える人の数 × 変わる大きさ**

| | 変わる人が多い | 変わる人が少ない |
|---|---|---|
| **表面が地味** | 渋いが一流（C1・C5） | 渋いだけ（X） |
| **表面が派手** | 一流（C3） | 派手だが二流（流行の題材で、識別が弱い） |

## 3. 検証の設計（案）

**トラック**: 3つのトラックのどれにも当たらない（論文を対象にした記述・予測の研究）。近いのは推定量・計量手法トラックの「性質を示す」型。扱いは D15 で決める。

| 項目 | 案 |
|---|---|
| 標本 | 一流（Econometrica、JoE、Econometric Theory、JBES、QE、REStat）、二流（JAE、Econometrics Journal、Econometric Reviews、JTSA など）、三流（Empirical Economics、Applied Economics、MDPI 系など）。各100〜300本、2015〜2024年 |
| 格の定義 | 通念ではなく、外部の格付けリスト（ABS/AJG、ABDC など）で決める。リストで格が割れる雑誌は感度分析に回す |
| 特徴量 | C1〜C6・X を、それぞれ複数の、はい／いいえの質問にする。文体の質問（上位誌らしい書き方、文法の誤り、決まり文句など）も入れて、文体と貢献の型を比べる |
| 判定 | 決定モデル（OpenAI Decisions API、Jev など）。人が付けた正解（例: 100本）で較正を確かめてから使う |
| 分析 | 型ごとに、一流誌での割合と三流誌での割合を比べる。格を目的変数にした順序ロジット。文体の質問を入れる前と後で比べる |
| 注意 | 要旨は著者の自己申告である。一流誌の要旨は「誤りを正す」と書く癖があるだけかもしれない。被引用数（掲載後の影響）でも確かめる |

### 数値の成功基準と棄却条件（仮。ロック前に人が決める）

| 仮説 | 支持 | 棄却 |
|---|---|---|
| H1: C1（誤りを正す）は一流誌に多い | 一流誌での割合が三流誌の2倍以上で、95%信頼区間が1倍を含まない | 比の95%信頼区間の上限が1.2倍を下回る |
| H2: X（小幅な拡張）は三流誌に多い | 三流誌での割合が一流誌の2倍以上 | 比の95%信頼区間の上限が1.2倍を下回る |
| H3: 貢献の型は文体を超えて格を説明する | 文体の質問を入れた後も、貢献の型の質問を足すと格の予測（順位相関）が0.05以上上がる | 上がり幅の95%信頼区間が0.02を下回る |

数値は仮置きである。検出力は標本を決めてから `sim/` で出す。

## 4. ラボにとっての意味

- 結果は、段階1の採点軸 Q（重要度）と N（新規性）の定義を直す根拠になる。例えば Q を「誰が何を変えるか」で、N を「既存の信念・手続きを変えるか」で採点する。
